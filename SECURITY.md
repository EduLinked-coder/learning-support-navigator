# Security and privacy

This repository is public. Do not open issues, pull requests or commits containing credentials, secret values, private company information, restricted material or identifiable learner/client data.

If protected material is discovered in public repository content, treat it as an information-boundary incident: stop further propagation, preserve only the minimum evidence needed to identify the affected revision, and route remediation through the appropriate private/governed channel rather than repeating the protected content publicly.

The paired private repository is not a source that may be copied from freely. Private access does not grant publication authority.

This repository does not provide a channel for clinical diagnosis, safeguarding case management, legal advice or regulatory determinations.
