# Contributing

Contributions should improve public learning navigation while protecting privacy, accessibility and the public/private boundary.

## Suitable contributions

- clearer public guidance or examples;
- accessibility improvements;
- tests or validation of public contracts;
- synthetic examples;
- corrections to public information with provenance.

## Do not contribute

- personal learner, family, client or provider case data;
- private company information or commercial evidence;
- proprietary methods that are not approved for public release;
- credentials, tokens, keys or secret values;
- diagnosis, clinical determinations or unsupported legal/regulatory conclusions.

## Accessibility expectations

Use clear structure and plain language. Web-facing work should be reviewed against WCAG 2.2 as the current design target, but contribution acceptance does not itself establish WCAG conformance.

## Private-source material

Do not copy material directly from `EduLinked-coder/learning-support-navigator-private`. Use the governed projection process. A private source must be explicitly classified `public_approved` and carry source revision, provenance and approval evidence before intake.
