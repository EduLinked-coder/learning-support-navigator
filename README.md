# Learning Support Navigator

> **Repository role:** Public, accessibility-first learning-navigation surface for EduLinked.
>
> **Operating principle:** **Autonomy by default. Human authority by exception. Evidence always.**

This repository helps people understand learning pathways, supports, adjustments, evidence, responsibilities and next actions in clear public language. It must remain useful without access to EduLinked private systems or proprietary product state.

## 🤖 Zero-context AI agent bootstrap

An authorised agent arriving without chat history SHALL:

1. read this `README.md` and treat the **public/private boundary as a hard gate**;
2. inspect the current repository tree, machine-readable boundary/projection contracts, schemas, tests and any current issue/continuation before creating new structure;
3. resolve whether the required fact belongs in this public repository or in `EduLinked-coder/learning-support-navigator-private` or another source-owning system;
4. search existing EduLinked learning/accessibility capabilities before creating another navigator, registry, schema, learning resource or support taxonomy;
5. use only public-safe, source-qualified facts and clearly synthetic examples;
6. preserve `UNKNOWN`, `NOT_FOUND_IN_SEARCHED_SCOPE`, `INACCESSIBLE`, `PRIVATE_SOURCE_EXISTS`, and `PUBLIC_PROJECTION_APPROVED` as distinct states;
7. make the smallest reversible public-safe change;
8. run applicable deterministic validation; and
9. reread the resulting public surface before claiming completion.

Reuse order:

`REUSE -> BIND -> CONFIGURE -> COMPOSE -> EXTEND_EXISTING -> CREATE_ONLY_IF_PROVEN_UNABSORBABLE`

## 🌐 Public boundary

This repository is public. Do not submit company-confidential material, restricted information, personal case data, credentials, secret values, private commercial evidence or proprietary methods that have not been approved for public release.

The paired private repository is `EduLinked-coder/learning-support-navigator-private`.

`PRIVATE_SOURCE_EXISTS != PUBLICATION_APPROVED`

`PRIVATE_FACT != PUBLIC_FACT`

`DERIVED_PUBLIC_PROJECTION != SOURCE_AUTHORITY_TRANSFER`

Only deliberately approved public-safe projections with provenance, source revision/currentness and publication authority may enter this repository.

## 🎯 What belongs here

- public learning-navigation guidance and examples;
- accessible explanations of learning pathways and support options;
- public-safe support and adjustment navigation concepts;
- public documentation and interfaces;
- synthetic examples that do not describe real people; and
- approved public projections from authorised private/source systems.

## 🚫 What does not belong here

- identifiable learner, family, provider or client case data;
- diagnosis, clinical determination or certification;
- ungoverned legal or regulatory conclusions;
- company-confidential or restricted information;
- private buyer, pricing, strategy or commercial evidence;
- credentials, tokens, keys or secret values; or
- claims that private/restricted evidence has been published merely because an agent found it.

## ♿ Accessibility and learner agency

WCAG 2.2 is the current design/review target for web-facing work, without claiming conformance until scope-appropriate operational evidence exists. Plain language, Easy Read where appropriate, keyboard access, readable structure, multiple ways to understand information, supported decision-making and non-diagnostic support are core expectations.

Preserve:

`ACCESSIBILITY_TARGET != VERIFIED_CONFORMANCE`

`SUPPORT_OPTION != PERSON_NEEDS_SUPPORT`

`ADJUSTMENT_AVAILABLE != ADJUSTMENT_SELECTED_OR_APPROVED`

`LEARNING_PATHWAY_INFORMATION != TRAINING_PROVIDER_ADVICE_OR_ENROLMENT`

`GUIDANCE != COMPETENCY_OR_RPL_DECISION`

## 🧭 Bounded non-diagnostic navigation workflow

The public synthetic example must prove only this narrow reusable navigation path:

`BARRIER_OR_CONCERN -> BOUNDED_SUPPORT_OPTION -> RESPONSIBLE_ACTOR -> REVIEW_OR_NEXT_ACTION`

The workflow stays general and public-safe. It does not decide what a real person needs, diagnose a condition, determine NCCD or legal entitlement, approve an adjustment, or claim an outcome. The responsible provider or other source-owning actor retains authority for its own process and decisions.

## 🔗 Ecosystem reuse boundary

Before creating new learning/support machinery, inspect relevant existing capability such as `EduLinked-Pty-Ltd/accessible-RTO`, `EduLinked-Pty-Ltd/Pilots`, `Sarah-Ailish-McLoughlin/practera`, `Sarah-Ailish-McLoughlin/client-accessibility-ops`, and the EduLinked Pattern Library where materially relevant.

This public repository should be a **thin public consumer** of source-owned capability. It must not become a duplicate RTO system, participant database, CRM, private evidence store or accessibility engine.

## 🧠 Evidence and claim discipline

For every consequential statement preserve source, currentness, provenance, audience/publication status and limitations.

`FOUND != VERIFIED`

`NOT_FOUND_IN_SEARCHED_SCOPE != DOES_NOT_EXIST`

`PUBLIC_GUIDANCE != CURRENT_REGULATORY_AUTHORITY`

`SYNTHETIC_EXAMPLE != REAL_PERSON`

`STRUCTURED_CONTENT != OPERATIONAL_OUTCOME`

A failed lookup is a search state, not evidence of absence.

## 🛡️ Authority

Agents may autonomously improve public-safe navigation, structure, accessibility, retrieval, examples, validation and bounded source-backed explanatory content within existing authority.

Protected human authority remains required for publication of sensitive/novel private-derived material, consequential legal/regulatory interpretations, person-specific recommendations, privacy/consent decisions, clinical/diagnostic claims, competency/RPL decisions and other protected representations.

## 🧪 Validation and maturity

Current source state is post-bootstrap. The repository contains a machine-readable public boundary, projection-intake contract, explicit bounded synthetic navigation workflow and deterministic boundary/workflow validation. These are implementation and runtime witnesses for their declared checks only.

Operational maturity still depends on stronger criterion-specific evidence and attributable real use. It is not inferred from repository structure or one successful workflow run alone.

`SCHEMA_VALID != FACT_TRUE`

`GREEN_CI != ACCESSIBLE_IN_PRACTICE`

`PUBLIC_PAGE_EXISTS != USER_OUTCOME`

`SYNTHETIC_WORKFLOW != REAL_USER_OUTCOME`

## ✅ Agent completion contract

Before handoff, state: what public-safe navigation state changed; source/provenance; public/private classification; accessibility/claim boundary; authority used; validation performed; unresolved gaps; and exact next safe action or re-entry trigger.

The next zero-context agent should never need chat history to decide whether a fact is safe to publish.
