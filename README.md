# Learning Support Navigator

A public, accessibility-first learning-navigation project from EduLinked.

This repository exists to help people understand learning pathways, supports, adjustments, evidence, responsibilities and next actions in clear public language. It must remain useful without access to EduLinked private systems or proprietary product state.

## Public boundary

This repository is public. Do not submit company-confidential material, restricted information, personal case data, credentials, secret values, private commercial evidence or proprietary methods that have not been approved for public release.

The paired private repository is `EduLinked-coder/learning-support-navigator-private`. Private material does not become public merely because it exists there. Only deliberately approved public-safe projections with source revision, provenance and approval evidence may be accepted here.

## What belongs here

- public learning-navigation guidance and examples;
- accessible explanations of learning pathways and support options;
- public-safe support and adjustment navigation concepts;
- public documentation and interfaces;
- synthetic examples that do not describe real people;
- approved public projections from the paired private repository.

## What does not belong here

- identifiable learner, family, provider or client case data;
- diagnosis, clinical determination or certification;
- ungoverned legal or regulatory conclusions;
- company-confidential or restricted information;
- private buyer, pricing, strategy or commercial evidence;
- credentials, tokens, keys or secret values.

## Accessibility

The project uses WCAG 2.2 as the current design and review target for web-facing work, without claiming conformance until scope-appropriate evidence exists. Plain language, keyboard access, readable structure, multiple ways to understand information and non-diagnostic support are core design expectations.

## Current maturity

Bootstrap foundation: machine-readable public boundary, projection-intake contract, synthetic navigation example and deterministic boundary validation. Operational maturity depends on retained workflow evidence and future real-world usage; it is not inferred from repository structure alone.
